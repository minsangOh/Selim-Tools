# Selim Tools

업무 효율화를 위한 Windows 데스크톱 프로그램 배포 저장소입니다.

## 프로그램

### Diff PDF
두 PDF 도면의 변경 영역을 비교하는 프로그램입니다.

### fileRay Selim
로컬 파일을 빠르게 검색하고 관리하는 프로그램입니다.

## 다운로드

오른쪽의 Releases 메뉴에서 최신 설치 파일을 다운로드하세요.

## 지원 환경

- Windows 10
- Windows 11

## 주의사항

본 저장소는 실행 파일과 사용자 매뉴얼만 제공합니다.
소스코드는 공개하지 않습니다.
